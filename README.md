# My Project

A three-page website built with semantic HTML and CSS, featuring a home page, about page, and an interactive contact form.

## Pages
- index.html: Home page of the project.
- about.html: Contains course details, pricing table, and study steps.
- contact.html: Includes a complete contact form with various input types.
